## Método Ventura

`EXPLORE → COMPILE → CONSTRAINED REPLAY → REGENERATE`

O objetivo é registrar decisões e critérios de avanço para tornar execuções futuras mais consistentes. O método não afirma determinismo de modelos de IA.

## Critério de progresso

- fundamentos demonstrados;
- projeto simples concluído;
- projeto intermediário documentado;
- especialização com portfólio;
- preparação para oportunidade real.
